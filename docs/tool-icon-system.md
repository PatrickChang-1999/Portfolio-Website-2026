# Tool icon system

Every tool image across Work, Experience, Capabilities, and both case studies uses the shared PNG files in dist/assets/tools. All ten files use a 256 by 256 canvas with the original artwork fitted within 224 by 224, preserving proportions. All icons were rasterized from vector sources with Inkscape and centered on transparent canvases. Power BI, Python, and Tableau use the Iconify logos collection; Alteryx uses Simple Icons in its blue brand color. These replace older PNGs with pale background squares. Word, PowerPoint, and Canva sources are documented in experience-tools.md. KNIME consistently uses the symbol across all pages.

Shared tool-icons.css sets 28px compact icons and 52px project-panel icons. Home and About have no tool icons; their text and institutional/company logos remain unchanged. Original SVG files are retained as editable source assets, but no page uses them for tool imagery.
