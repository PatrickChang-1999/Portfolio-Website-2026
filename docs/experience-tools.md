# Experience tool rows

Every role uses a 24px icon followed by its text label.

- Business Analyst: Power BI, SQL, Excel, KNIME, Python.
- Student Data Analyst: Python, Alteryx, Tableau, Power BI.
- Digital Marketer: Word, Excel, PowerPoint, Canva.

Existing analytics assets are reused. Word and PowerPoint SVGs are sourced from the vscode-icons collection via @iconify-json/vscode-icons; Canva is sourced from Simple Icons via @iconify-json/simple-icons. Both collections were retrieved as SVG data through jsDelivr.
