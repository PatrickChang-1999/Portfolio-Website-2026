# 0205 dark pressed titles

Applied to Home, Work, Experience, Capabilities and About. The original #37332d ink, typography and layout are retained.

The decorative SVG filter adds deterministic, monochrome fine grain clipped to the letterforms, with color variation centered on the original charcoal. A 2.6px upper inset shadow and narrow lower highlights make the recessed edge clearer without lightening the broad letter faces. Grain is static; no animation or new image requests are added. CSS text shadows are disabled so the filter receives only the actual glyph silhouette.

The SVG is aria-hidden and occupies no layout space. Titles remain real selectable heading text. Print, forced-color and increased-contrast modes disable the filter. Existing page animations, reduced-motion behavior, cards, content, icons and contour waves are unchanged.
